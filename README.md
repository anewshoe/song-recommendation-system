## Overview
A content-based music recommendation system that uses machine learning and audio feature similarity to recommend songs based on one chosen song.

The system combines a Multi-Layer Perceptron (MLP) classifier, an autoencoder, and cosine similarity to identify songs with similar musical characteristics. Recommendations are generated using a weighted combination of learned song representations and numerical audio features.

## Development Environment

This project was developed using Jupyter Notebook in a university-hosted DataHub environment as part of an Introduction to Artificial Intelligence course.

The notebook contains the data preprocessing, model training, recommendation generation, and evaluation workflows.

**Note:** The original Spotify dataset and generated model files are not included in this repository. Reproducing the results may require obtaining the dataset separately, configuring the necessary Python dependencies, and retraining the models.

## Dataset

This project uses a Spotify music dataset from Kaggle, provided by Solomon Ameh, containing approximately 1.16 million tracks.
